# Screenshot Checklist

These still need to be produced manually from real devices or simulator builds.

## App Store

Capture at least:

- Search map with live price pins
- Listing page with imagery, pricing, and availability
- Booking summary / payment confirmation
- Booking detail with arrival details
- Host listing creation / review screen

## Play Store

Capture at least:

- Search map
- Listing page
- Booking summary
- Booking history
- Host dashboard or listing creation

## Rules

- Use production branding and current UI
- Avoid placeholder or test data that looks broken
- Ensure pricing, dates, and listing titles look realistic
- Do not use dev labels or debug banners
