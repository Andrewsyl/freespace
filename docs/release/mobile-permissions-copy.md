# Mobile Permissions Copy

Use this copy when filling App Store / Play Store permission disclosures and review notes.

## Location

Why we ask:

- to center the map on the driver
- to search for parking near the current area
- to provide navigation context for booked spaces

User-facing explanation:

`FreeSpace uses your location to show nearby parking spaces and help you navigate to a booked space.`

## Camera

Why we ask:

- to let hosts upload listing photos

User-facing explanation:

`FreeSpace uses your camera so hosts can add listing photos.`

## Photo Library

Why we ask:

- to let hosts upload listing images from the device library

User-facing explanation:

`FreeSpace uses your photos so hosts can upload images for their listings.`

## Notifications

Why we ask:

- booking reminders
- booking status updates
- host booking notifications

User-facing explanation:

`FreeSpace uses notifications for booking reminders and status updates.`
